### 禁止重复测试

> **重复测试 = 浪费生命。只有以下情况才重复测试：**
>
> 1. **信号不明确**：提升/下降在 5% 以内，需要确认
> 2. **调试需要**：验证编译是否正确（看编译输出，不跑完整测试）
> 3. **用户要求**：用户明确要求重新测试

> **不需要重复测试的情况：**
> - 验证回退成功（看编译，不跑测试）
> - 同一个实验方向已经跑过 3+ 次
> - 信号已经明确（提升 >15% 或下降 >10%）

## 架构差异分析

### Team_Kitty_Knight (9.039)
```
causal_pibt->multi_step() → LNS全局优化 → actions
```

### 我们当前架构 (H1 baseline)
```
plan() → 单次FW优化 → actions
```

**核心差距**：LNS在每步做全局优化，我们只在step 0做一次
