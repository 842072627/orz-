# Pre-Experiment Checklist

> 每次实验前必须检查，不满足条件不跑测试

## 检查清单

- [ ] **假设**：我预期X变化会发生，因为Y原因
- [ ] **成功标准**：具体提升多少算成功？
- [ ] **测试上限**：最多测N次
- [ ] **失败结论**：如果失败，说明什么？

## 规则

1. **任何一项空白 = 不跑测试**
2. **超过测试上限 = 必须停止**
3. **没有代码改动 = 不跑测试验证稳定性**（3-5次足够）
4. **20次测试上限** - 超过必须停下来问"我在干嘛"

## 记录格式

```
假设：...
成功标准：...
测试上限：...
失败结论：...

实际结果：...
结论：...
```

---

## 常见错误

❌ "分数稳定，再跑几次确认"
→ 稳定不需要反复测试，3-5次足够

❌ "改代码试试效果"
→ 没有假设就不改

❌ "没提升所以再调调参数"
→ 5次没提升就换方向，不是继续调

✅ "假设X会提升Y，测3次看效果"
