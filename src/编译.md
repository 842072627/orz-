# LoRR 编译指南 (Windows)

> 2026-05-14 首次配置记录
> 当前分支: `room` | 编译器: `MSYS2 g++ 15.2.0`

---

## 环境要求

| 组件 | 版本 | 路径 |
|------|------|------|
| CMake | ≥ 3.16 | `C:\Program Files\CMake\bin` |
| MinGW-w64 (MSYS2 UCRT) | g++ 15.2.0 | `C:\msys64\ucrt64\bin` |
| Boost | 1.90.0 (共享库) | `C:\msys64\ucrt64` |
| Python | 3.14.4 | `C:\msys64\ucrt64` |
| pybind11 | 3.0.2 | `C:\msys64\ucrt64` |

## 🚫 已知不兼容的编译器

| 编译器 | 失败原因 |
|--------|----------|
| **llvm-mingw clang + libc++** | MinGW math.h 宏 (isinf/isnan/signbit) 与 libc++ 冲突 |
| **MSVC (Visual Studio)** | MSYS2 Boost 头文件含 GCC 扩展语法，MSVC 无法解析 |

**只有 MSYS2 原生 g++ 可以编译成功。**

## 编译步骤

### 1. 配置 CMake

```powershell
$env:Path = "C:\msys64\ucrt64\bin;C:\Program Files\CMake\bin;$env:Path"
cd LORR26_842072627
Remove-Item -Recurse -Force build -ErrorAction SilentlyContinue
cmake -G "MinGW Makefiles" `
  -DCMAKE_C_COMPILER="gcc" `
  -DCMAKE_CXX_COMPILER="g++" `
  -DCMAKE_PREFIX_PATH="C:\msys64\ucrt64" `
  -DBoost_USE_STATIC_LIBS=OFF `
  -DPYBIND11_FINDPYTHON=ON `
  -S . -B build
```

### 2. 编译

```powershell
$env:Path = "C:\msys64\ucrt64\bin;C:\Program Files\CMake\bin;$env:Path"
cmake --build build -j8
```

### 3. 运行测试

#### Room 地图 (150 agents, 64×64)

```powershell
$env:Path = "C:\msys64\ucrt64\bin;$env:Path"
.\build\lifelong.exe `
  -i "example_problems/room.domain/room-example_150.json" `
  -s 1100 -c 1 -o room_R1_test.json
```

#### ORZ 地图 (1800 agents, 256×256)

```powershell
$env:Path = "C:\msys64\ucrt64\bin;$env:Path"
.\build\lifelong.exe `
  -i "example_problems/game.domain/orz-example_1800.json" `
  -s 1100 -c 1 -o orz_test.json
```

## 常用命令参数

| 参数 | 说明 |
|------|------|
| `-i <file>` | 输入 JSON (问题定义) |
| `-s <steps>` | 模拟步数 (1100 快速调试 / 2800 正式) |
| `-c 1` | **必须** 输出完整 JSON (含 actualPaths) |
| `-o <file>` | 输出 JSON 文件路径 |
| `-c 3` | **不要用** 只输出摘要(无路径数据) |

## 🔴 规则红线

编译和使用 `lifelong.exe` 时严格遵守 `RULES_CHECKLIST.md`：

- **不可修改的文件**: `default_planner/*`, `inc/*`, `src/TaskManager.cpp`, `src/Simulator.cpp` 等
- **所有修改必须在 `src/` 下的可修改文件清单内** (详见规则清单)
- `src/Logger.cpp` 是本地 stub，提交前必须恢复为官方版本
