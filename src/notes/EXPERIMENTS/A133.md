## 核心思路

不实现完整的 SIPP。简单冲突检测 + 基于冲突的邻居选择：

1. **Phase 1**: 实现 `has_temporal_conflict()` 检测两条轨迹的时间冲突
2. **Phase 2**: 只选择冲突数最多的 neighbor_size 个 agent 重规划

## 实现计划

### Phase 1: 冲突检测

在 `my_flow.cpp` 中添加：

```cpp
// 检测两条轨迹是否有时空冲突
bool has_temporal_conflict(const std::vector<int>& traj1, const std::vector<int>& traj2) {
    int len1 = traj1.size();
    int len2 = traj2.size();
    int min_len = std::min(len1, len2);
    
    for (int t = 0; t < min_len; t++) {
        if (traj1[t] == traj2[t]) {
            return true;  // 同时占据同一位置
        }
    }
    return false;
}
```

### Phase 2: 基于冲突的邻居选择

修改 `frank_wolfe`：
1. 计算每个 agent 的冲突数
2. 选择冲突数最多的 neighbor_size 个
3. 只重规划这些 agent
