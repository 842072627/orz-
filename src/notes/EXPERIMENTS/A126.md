# A126: Room 地图 LNS neighbor_size 优化 (2026-04-23)

## 目标
提升 room 分数 (当前 ~0.188，目标 0.88)

## 背景

### A112 结果
- frank_wolfe neighbor_size=8 对 room 有帮助
- room 从 0.152 → 0.188 → 0.205 (最终 ~0.188)

### room 地图特征
- 64x64 开放地图，11% 障碍物
- 150 agents
- **房间之间有多个狭窄走廊连接**
- LNS 需要更多邻居来协调走廊中的 agents

## 实现 (A126)

### 修改内容
```cpp
// A126: Room-specific neighbor_size - larger for room's corridor topology
int neighbor_size = 8;  // default
std::string map_name = lns.env->map_name;
std::transform(map_name.begin(), map_name.end(), map_name.begin(), ::tolower);
if (map_name.find("room") != std::string::npos) {
    neighbor_size = 16;  // room has many corridors, needs more neighbors
}
```

### 测试结果 ❌
- **neighbor_size=16**: room = 0.165 (从 0.188 下降!)
- **neighbor_size=8**: room = 0.188 (baseline)

### 失败原因分析
- neighbor_size=16 太大了，每轮处理太多 agents
- 每轮只有 `remaining_ms / neighbor_size` 时间
- neighbor_size=16 时每 agent 只有一半时间
- 导致路径质量下降

## 结论
- room 用 neighbor_size=8 已经是最优的
- neighbor_size=16 太大，导致时间不足
