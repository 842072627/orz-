# A124: SIPP-Aware A* 实现 (2026-04-23)

## 目标
为 random 地图实现 SIPP-aware A*，从 0.52 提升到 0.98+

## Team_RAPID 的方法

### TimeSpaceAStarPlanner 关键特点
1. **动态节点分配**: 不使用 MemoryPool，直接在 heap 上分配节点
2. **State 包含 timestep**: 每个状态记录 (pos, orient, t)
3. **ConstraintTable 检查**: `constrained(from, to, t)` 检查边是否被占用

### 我们的方法

由于 MemoryPool 使用 location 作为 key，不支持同一 location 的多个时间步状态，
我们需要一个不同的方法。
