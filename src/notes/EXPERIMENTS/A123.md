## 目标
提升 random 分数 (当前 0.52，目标 0.98+)

## 研究结论

### Team_RAPID 架构
1. **TimeSpaceAStarPlanner**: A* + 时间维度 + 约束表
2. **ConstraintTable**: 追踪位置/边的时隙约束
3. **PP (Priority Planner)**: 按优先级顺序重规划agent路径

### 关键区别
- 我们的 A*: 只检查位置是否被占用
- Team_RAPID 的 A*: 检查位置在特定时间是否被占用

### SIPP 核心概念
```cpp
// 检查边 (from, to) 在时间 t 是否被占用
constraint_table.path_table_for_CT->constrained(from, to, t)

// Safe interval: 位置 [t_start, t_end) 空闲
```
