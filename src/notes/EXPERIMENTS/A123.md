## Team_RAPID SIPP 架构

### 核心组件
1. **ConstraintTable**: 追踪位置/边的约束
2. **ReservationTable**: 计算安全区间 (safe intervals)
3. **SIPP**: 使用安全区间的 A* 变体

### SIPP 关键概念

```cpp
// Safe interval: [t_min, t_max), has_collision
typedef tuple<int, int, bool> Interval;

// ReservationTable 追踪每个位置的安全区间
list<tuple<int, int, int, bool, bool> > get_safe_intervals(...);

// SIPP 节点包含 interval 信息
SIPPNode {
    Interval interval;  // 当前位置的安全区间
    int g_val;         // 实际代价
    int h_val;         // 启发式代价
}
```

### SIPP vs 普通 A* 的区别

**普通 A***:
- 只检查位置是否被占用
- 不考虑时间冲突

**SIPP**:
- 追踪每个位置的"安全区间"
- 在 A* 搜索时考虑其他 agents 何时会占用位置
- 避免时间上的冲突
