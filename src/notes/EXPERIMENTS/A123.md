### Team_RAPID 架构
1. **TimeSpaceAStarPlanner**: A* + 时间维度 + 约束表
2. **ConstraintTable**: 追踪位置/边的时隙约束
3. **PP (Priority Planner)**: 按优先级顺序重规划agent路径
4. **sipp=true**: 启用时隙敏感的路径规划

### 我们现有的基础设施
1. **PathTable** (my_PathTable.h): 有 `constrained()` 和 `edgeConstrained()` 检查
2. **TimeSpaceAStarPlanner** (my_TimeSpaceAStarPlanner.h): 但注释说 "SIPP not implemented yet"
3. **ReservationTable** (default_planner/ReservationTable.h): 我创建的最小实现

### 核心问题
- 我们的 A* 只检查位置是否被占用
- Team_RAPID 的 A* 检查位置在特定时间是否被占用
- 我们的 TimeSpaceAStarPlanner 说 "SIPP not implemented yet"

## SIPP vs 普通 A* 的区别

**普通 A***:
```cpp
// 只检查位置是否被占用
if (is_occupied(next)) continue;
```

**SIPP**:
```cpp
// 检查位置在特定时间是否被占用
if (path_table.constrained(next, arrival_time)) continue;

// 或者更复杂：找到下一个空闲时间
int free_time = path_table.getHoldingTime(next, arrival_time);
if (free_time > arrival_time) {
    // 需要等待或找替代路径
}
```
