## SIPP 实现难点

### 1. MemoryPool 限制
当前 MemoryPool 使用 location 作为 key，不支持同一 location 的多个时间步状态。

Team_RAPID 的方法：使用 heap 分配 + set 跟踪，而不是预分配的 MemoryPool。

### 2. A* 修改
需要在 successor generation 时检查 PathTable:
```cpp
if (path_table.constrained(next_pos, curr_timestep + 1)) {
    continue; // 跳过被占用的位置
}
```
