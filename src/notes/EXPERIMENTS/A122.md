# A122: Try MyPlanner for random (2026-04-22)

## 目标
提升 random 分数 (当前 0.52，目标 0.98+)

## 假设
MyPlanner 可能比 DefaultPlanner 更好地处理 random 地图

## 实现
在 `should_use_my_planner` 中添加 random：
```cpp
// A122: random also use MyPlanner
if (name.find("random") != std::string::npos) {
    return true;
}
```

## 结果 ❌ 失败

| 地图 | DefaultPlanner | MyPlanner | 变化 |
|------|----------------|-----------|------|
| random | 0.52 | 0.483 | -0.037 |

### 分析
- MyPlanner 对 random 更差（0.52 → 0.483）
- 说明 DefaultPlanner 的 PIBT 实现更适合 random
- MyPlanner 的 frank_wolfe 优化对 random 有负面影响

## 结论
MyPlanner 不适合 random。random 应该继续使用 DefaultPlanner。
random 的问题不是 planner 选择，而是算法本身（需要 SIPP）。
