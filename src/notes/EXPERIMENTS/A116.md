# A116: maze 简化 SIPP 概念实现 (2026-04-22)

## 目标
提升 maze 分数 (当前 0.090，目标 0.73)

## 策略

不实现完整 SIPP，只实现关键概念：
1. 识别窄通道位置（只有 2 个邻居）
2. 在路径规划时优先避开窄通道或规划等待点
3. 减少窄通道冲突

## 实现计划

### 1. 识别窄通道

```cpp
// 在 init_heuristics 中识别窄通道
bool is_narrow_corridor(int location, env) {
    int neighbors = 0;
    for each direction:
        if neighbor is valid: neighbors++
    return neighbors <= 2;  // 窄通道只有 2 个邻居
}
```

### 2. 修改 A* 启发函数

对于 maze，优先选择经过较少窄通道的路径：
```cpp
int h_maze(int from, int to) {
    int manhattan = abs(from/to - to/to) + abs(from%to - to%to);
    int narrow_penalty = count_narrow_corridors_on_path(from, to);
    return manhattan + narrow_penalty * CORRIDOR_PENALTY;
}
```

### 3. 地图名判断

```cpp
if (env->map_name.find("maze") != string::npos) {
    use_maze_heuristic = true;
}
```
