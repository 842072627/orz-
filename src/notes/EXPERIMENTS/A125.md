# A125: 改进 LNS 邻居选择 (2026-04-23)

## 目标
改进 LNS 邻居选择逻辑，选择真正需要重规划的 agents

## 当前问题
- frank_wolfe 按 deviation 排序选择 agents
- 不考虑 agents 之间的潜在冲突
- 可能导致反复重规划同一区域

## Team_RAPID/Team_Kitty_Knight 方法
- 并行框架：同时重规划多个 agents
- 冲突感知选择：优先选择有冲突的 agents
- 批量处理：一次处理多个 agents

## 实现计划

### Phase 1: 冲突检测
在 frank_wolfe 开始前，检测哪些 agents 之间有潜在冲突
- 位置冲突：两个 agents 要去同一个位置
- 边冲突：两个 agents 要穿过同一条边
- 交换冲突：两个 agents 要互换位置

### Phase 2: 冲突感知排序
根据冲突调整重规划顺序
- 有冲突的 agents 优先重规划
- 避免重复重规划

### Phase 3: 批量重规划（可选）
一次重规划多个相关的 agents
- 需要架构改动
