# A119: Random 地图 neighbor_size=16 尝试 (2026-04-22)

## 目标
提升 random 分数 (当前 0.530，目标 0.98+)

## 策略
增加 random 地图的 neighbor_size，给每个 agent 更多规划时间

## 实现
```cpp
// A119: random 使用 neighbor_size=16
if (name.find("random") != std::string::npos) {
    neighbor_size = 16;  // 从 8 增加到 16
}
```

## 结果 ❌ 失败

| 地图 | 分数 | 变化 |
|------|------|------|
| random | 0.513 | -0.017 (变差) |
| room | 0.180 | +0.008 |
| fulfill | 1.079 | -0.003 |

### 分析
- neighbor_size=16 意味着每轮只处理 16 个 agent
- 但时间没有相应增加，导致每个 agent 的 deadline 减少
- random 的 400 agents 需要更多 agent 同时规划

## 结论
neighbor_size=16 太大，导致每个 agent 时间不足。应该保持 neighbor_size=8。
