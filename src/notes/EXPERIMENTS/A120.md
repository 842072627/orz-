# A120: Conflict-based Neighbor Selection (2026-04-22)

## 目标
提升 random 分数 (当前 0.530，目标 0.98+)

## 策略
实现 Team_RAPID 式的 conflict-based neighbor selection：
1. 找到冲突最多的 agent
2. 收集与其冲突的其他 agents 作为邻居
3. 优先重规划这些冲突的 agents

### 分析
- Conflict detection 太慢（对50个agents采样）
- 时间不够导致实际规划的 agents 数量减少
- random 和 fulfill 都变差了

## 结论
Conflict-based selection 思路正确，但实现有问题：
1. 采样检测冲突太慢
2. 需要更高效的冲突检测算法
