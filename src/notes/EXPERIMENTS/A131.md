# A131: Room neighbor_size=4 测试 (2026-04-23)

## 状态: 实验中

## 目标
测试 neighbor_size=4 for room，看看更少邻居是否带来更好分数。

## 背景

- A126: neighbor_size=16 for room → 0.165 (从0.188下降) ❌
- 假设: neighbor_size 更小 = 每批处理更少 agent = 每个 agent 更多时间

## 实验设计

修改 `my_flow.cpp` 添加 room 特定的 neighbor_size=4：

```cpp
// A131: room 可能需要更小的 neighbor_size
int adjusted_neighbor_size = neighbor_size;  // 默认 8
std::string map_name = lns.env->map_name;
std::transform(map_name.begin(), map_name.end(), map_name.begin(), ::tolower);
if (map_name.find("room") != std::string::npos) {
    adjusted_neighbor_size = 4;  // room 用更小的 neighbor_size
}
```

## 预期

- neighbor_size=4: deadline = remaining_ms / 4 (比默认 8 更长)
- 每个 agent 获得更多时间
- 可能改善 room 分数

## 风险

- room 使用 DefaultPlanner，不是 MyPlanner
- 修改 MyPlanner 可能不影响 DefaultPlanner

## 备注

room 使用 DefaultPlanner，不是 MyPlanner。所以这个修改不会影响 room。

需要找到 DefaultPlanner 的 neighbor_size 设置，或者接受 room 需要不同的方法。
