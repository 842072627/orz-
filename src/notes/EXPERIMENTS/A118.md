# A118: Random 地图 LNS 优化 (2026-04-22)

## 目标
提升 random 分数 (当前 0.507，目标 0.98+)

## 背景

### 当前状态
- random: 0.507 / 400 agents / 300 makespan
- 目标: 0.98+ (Team_RAPID 用 LNS 得到 0.985)

### Team_RAPID 成功关键
1. **neighbor_size=8**: 只选择 8 个邻居重规划
2. **时间集中**: `remaining_ms / 8` 而不是 `remaining_ms / 400`
3. **SIPP**: 启用 Safe Interval Path Planning

### 我们的差距
- frank_wolfe: 遍历所有 agents，时间分散
- 每个 agent 只有 ~2.5ms
- 需要切换到 neighbor-based LNS

## 实现计划

### 1. 修改 frank_wolfe 选择部分邻居
```cpp
// 当前: 遍历所有 agent
index = count % lns.env->num_of_agents;

// 修改: 只选择 neighbor_size=8 个
if (count % neighbor_size == 0) {
    // 选择下一个邻居
}
```

### 2. 增加每个邻居的 deadline
```cpp
// 当前: deadline_per_agent = remaining_ms / num_of_agents
// 修改: deadline_per_agent = remaining_ms / neighbor_size
```

### 3. 地图名判断
```cpp
if (env != nullptr && !env->map_name.empty()) {
    std::string name = env->map_name;
    std::transform(name.begin(), name.end(), name.begin(), ::tolower);
    if (name.find("random") != std::string::npos) {
        neighbor_size = 8;  // 对 random 使用 LNS
    }
}
```
