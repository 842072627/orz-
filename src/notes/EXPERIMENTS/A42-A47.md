# A42: 跳过 frank_wolfe for tight maps

- 创建时间: 2026-04-22
- 实验ID: A42
- 状态: ✅ 已推送

## 假设
frank_wolfe 在 room/maze/iron/orz 等 tight 地图上收敛慢，导致超时崩溃。

## 改动
```cpp

    name.find("maze") != std::string::npos ||
    name.find("iron") != std::string::npos ||
    name.find("orz") != std::string::npos) {
    return true;  // 跳过 frank_wolfe
}
```

## 结果
- room: 0.168 (之前崩溃)
- maze: 0.092 (之前崩溃)
- iron: 0.147 (之前崩溃)
- orz: 0.215 (之前崩溃)
- **Total: +0.08 提升**

## 结论
✅ 有效。frank_wolfe 在 tight 地图上确实是负担。
