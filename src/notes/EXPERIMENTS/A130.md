## 目标
实现 SIPP (Safe Interval Path Planning) 来解决 random/maze/room 的时间维度冲突问题。

## 问题根源

### PIBT 的局限性
PIBT 只检查"当前时刻"位置是否被占用，不检查"未来时刻"的位置冲突。

```cpp
// PIBT 检查（简化）
if (occupied[next.location]) {
    continue;  // 只检查当前时刻
}
// 不检查 next.location 在未来时刻是否被占用
```

### SIPP 的解决方案
SIPP 使用安全时间间隔 (safe intervals) 来追踪位置在哪些时刻是可用的。

```cpp
// SIPP 概念
struct SIPPNode {
    int location;
    int timestep;
    int interval_start;  // 安全间隔开始
    int interval_end;    // 安全间隔结束
};
```
